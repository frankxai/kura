# Kura Web Store Screenshots

The Chrome Web Store requires 5 high-fidelity screenshots (1280x800) of the extension in action. Please capture the following screenshots and place them in this folder.

## Required Screenshots (1280x800)

| # | Filename | Description | Web Store Caption (≤ 132 chars) |
|---|---|---|---|
| 1 | `1_chatgpt.png` | Popup open on a ChatGPT tab, "Conversations 1" highlighted | One click captures the entire conversation, prompts and images to a folder on your disk. |
| 2 | `2_format.png` | Popup with format dropdown open, showing Markdown / JSON / HTML / Plain text | Pick a format. Markdown is Obsidian-ready out of the box. |
| 3 | `3_obsidian.png` | Obsidian graph view of a 50-conversation Kura/ vault | Drop the folder into Obsidian. The knowledge graph builds itself. |
| 4 | `4_vscode.png` | Conversation.md file open in VS Code showing the YAML frontmatter | Every conversation gets a YAML contract that worldbuilding skills can read. |
| 5 | `5_claudecode.png` | Claude Code terminal showing `/kura-process` extracting entities | Run /kura-process to turn raw captures into a linked entity graph. |

## Capture Guidelines

- **Dimensions:** Exactly 1280x800 pixels.
- **Build:** Use the production build loaded from the unpacked `dist/` directory, NOT the dev server.
- **Visuals:** Ensure the new teal/gold tokens are visible, not the old purple styling.
- **Content:** Use real conversations about creative topics (worldbuilding, writing) rather than technical support threads, as the primary audience is creators.
- **Backgrounds:** Ensure the background browser content is a real platform UI (ChatGPT, Claude, etc.), not stubbed or empty.
